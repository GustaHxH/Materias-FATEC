# App Hub de Utilidades

Aplicativo Android desenvolvido em Java que reúne várias ferramentas em um único lugar.

##  Funcionalidades

*  **MegaSena**
  Gera 6 números aleatórios sem repetição.

*  **IMC**
  Calcula o Índice de Massa Corporal com base no peso e altura, mostrando a classificação.

*  **Jokenpo**
  Jogo contra o computador com sistema de melhor de 3 e placar.

*  **Questionário da Felicidade**
  Calcula um nível de felicidade com base em sono e estresse, exibindo uma pontuação de 0 a 10.

##  Navegação

O app possui um menu principal com botões para acessar cada funcionalidade.
Cada tela possui opção de retorno ao menu inicial.

##  Tecnologias

* Java
* Android Studio
* Activities e Intents

##  Objetivo

Praticar:

* Navegação entre telas
* Passagem de dados entre Activities
* Lógica condicional
* Organização de múltiplos módulos em um único app
