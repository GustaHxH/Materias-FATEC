# Projeto IMC com CRUD

Este projeto foi desenvolvido em Android Studio utilizando Java e SQLite.

O aplicativo realiza o cadastro de usuários contendo:
- Nome
- Idade
- Altura
- Peso

Com base nas informações fornecidas, o sistema calcula o IMC (Índice de Massa Corporal) e exibe o resultado em uma segunda tela junto com a classificação do usuário.

Além disso, o projeto possui um CRUD completo com banco de dados SQLite, permitindo:
- Inserir dados
- Consultar usuários
- Atualizar informações
- Deletar registros

Tecnologias utilizadas:
- Java
- Android Studio
- SQLite
- Material Design
