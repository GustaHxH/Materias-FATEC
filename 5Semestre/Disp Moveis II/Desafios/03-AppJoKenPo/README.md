Jokenpo Android

App de Pedra, Papel, Tesoura em Android (Java).

Funcionalidades

Placar permanente: “PC [ - ] x [ - ] Você”

Melhor de 5: quem fizer 3 pontos primeiro vence

Reset automático ao final da partida

Botão de reset manual

Clique nas imagens para jogar

Como usar

Abra o projeto no Android Studio

Compile e rode no emulador ou dispositivo

Clique em Pedra, Papel ou Tesoura para jogar

Placar e resultado atualizam automaticamente

Use o botão Resetar para começar de novo
