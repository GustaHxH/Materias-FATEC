# 06 Video Button

Projeto desenvolvido em Android Java utilizando VideoView para reprodução de vídeos locais armazenados na pasta `res/raw`.

## Funcionalidades

- Reprodução de vídeos
- Pausar vídeo
- Barra de progresso com SeekBar
- Exibição do tempo atual e duração do vídeo
- Botões para selecionar diferentes vídeos
- Interface simples e intuitiva

## Tecnologias Utilizadas

- Java
- Android Studio
- VideoView
- SeekBar
- MediaPlayer

## Estrutura dos Vídeos

Os vídeos utilizados devem estar dentro da pasta:

res/raw
