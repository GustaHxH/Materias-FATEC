**APP SIMULADOR DA MEGA SENA**



Um app JAVA, que simula um sorteio da Mega Sena







**FUNCIONALIDADE**



Gera 6 números de 1 a 60, onde os números não podem se repetir para ser mais fiel a um sorteio de verdade.



Simples e fácil de usar.



Contem um botão de sorteio e um para limpar o sorteio.







**COMO USAR**



Abra o app.



Clique em **SORTEAR** para gerar os 6 números sorteados.



Clique em **LIMPAR** para limpar os números sorteados.







**TECNOLOGIAS**



JAVA
